# RouteGenie: AI Travel Logistics Assistant

**Elevator Pitch:**
Проєкт призначений для мандрівників, які планують складні маршрути по Європі. На відміну від звичайних агрегаторів, RouteGenie використовує RAG для надання порад щодо конкретних вокзалів та вузьких місць у пересадках, а також інтелектуально розраховує бюджет з урахуванням знижок.

**Цільова аудиторія:** Студенти, бекпекери, самостійні мандрівники.

**Технології:**
- Python 3.10+
- Google Gemini 1.5 Flash API
- Streamlit (UI)
- RAG (завантаження локального контексту про вокзали)

**Як запустити:**
1. Встановіть залежності: `pip install streamlit google-generativeai`
2. Вставте ваш API Key у змінну `GOOGLE_API_KEY` в коді.
3. Запустіть: `streamlit run main.py`
