# 🌍 RouteGenie AI: Інтелектуальний Логіст для Подорожей

**RouteGenie AI** — це прототип сучасного ШІ-асистента для планування складних маршрутів по Європі. Проєкт реалізований як веб-додаток з інтерфейсом у стилі месенджера, що підтримує роботу з декількома чатами одночасно.

---

## 🚀 Ключові особливості (Elevator Pitch)
- **Цільова аудиторія:** Студенти та самостійні мандрівники.
- **Проблема:** Труднощі при плануванні пересадок на великих вокзалах та пошук актуальних правил пільгового проїзду.
- **Рішення:** Використання новітньої моделі **Gemini 3.1 Flash Lite** у поєднанні з власною базою знань (RAG) для надання точних логістичних порад.

---

## 🛠 Технічна реалізація та Паттерни

Проєкт демонструє використання просунутих ШІ-паттернів:

1.  **RAG (Retrieval-Augmented Generation):** Бот аналізує локальний файл `knowledge.txt`, що містить специфічну інформацію про ремонти на вокзалах та умови студентських знижок, якої немає в базових знаннях моделі.
2.  **Short-term Memory (Контекст):** Реалізовано збереження історії діалогу в межах сесії. Бот пам’ятає попередні повідомлення користувача для уточнення маршруту.
3.  **Multi-Chat Management:** Система керування станом (`st.session_state`), що дозволяє створювати, зберігати та перемикатися між різними чатами без втрати контексту.
4.  **Dynamic Model Selection:** Алгоритм автоматичного підбору найбільш стабільної версії API (від 3.1 Flash Lite до Gemini Pro).

## 📦 Встановлення та запуск

### 1. Вимоги
- Python 3.10+
- Ключ API від Google AI Studio

### 2. Встановлення залежностей
```bash
pip install streamlit google-generativeai

3. Налаштування файлів
Переконайтеся, що файл main.py та knowledge.txt знаходяться в одній директорії.

Вставте ваш API Key у змінну GOOGLE_API_KEY у файлі main.py.

4. Запуск програми

python -m streamlit run main.py
